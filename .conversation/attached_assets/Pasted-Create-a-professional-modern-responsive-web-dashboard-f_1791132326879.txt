ACCESS ENGINEERING PLC

PROJECT NAME:
Peliyagoda Concrete Plant – Plan vs Actual Operations & Delay Dashboard

==================================================
1. MAIN PURPOSE
==================================================

The main purpose of this dashboard is to manage the daily concrete production/delivery planning process and then record the actual operation.

The system must compare:

DAILY PLAN
vs
ACTUAL OPERATION

and automatically calculate:

- Time differences
- Delivery/operation delays
- Volume differences
- Truck differences
- Planned vs actual performance
- Delay reasons
- Delay trends

The most important purpose is to identify and measure operational delays.

The dashboard should answer:

"What did we plan?"
"What actually happened?"
"How much difference occurred?"
"How many minutes were delayed?"
"Why did the delay happen?"
"Which projects/customers have recurring delays?"

Do NOT make this a generic data-entry dashboard. Make it an operational performance monitoring system.

FINISH TIME:

Actual Last Truck Returned
MINUS
Planned Finish

Actual Last Truck Returned = 11:48

VOLUME:

Actual Volume
MINUS
Planned Volume

Actual = 76 m³

Volume Difference = -4 m³

TRUCKS:

Actual Trucks Used
MINUS
Allocated Trucks

Example:

Allocated = 6
Actual = 7

Truck Difference = +1

7. DELAY LOGIC
==================================================

The dashboard must automatically identify whether an operation was delayed.

Rules:

If actual time <= planned time:
ON TIME

If actual time > planned time:
DELAYED

Calculate delay in minutes.

Example:

0 minutes = On Time
10 minutes = 10 min delay
25 minutes = 25 min delay
60 minutes = 1 hour delay

Do NOT hide the actual delay value.

Display delay clearly in minutes.

Use visual status indicators:

On Time
Minor Delay
Moderate Delay
Major Delay

Suggested thresholds:

0 minutes or less:
On Time

1–15 minutes:
Minor Delay

16–30 minutes:
Moderate Delay

More than 30 minutes:
Major Delay

Make these thresholds configurable later.
